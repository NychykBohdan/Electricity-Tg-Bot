## ⚡ Світло-бот (MVP)

Telegram-бот, який показує графіки відключень і попереджає про зміни.

**Що вміє**

*   визначення черги за особовим рахунком (або вручну, якщо номер невідомий)
*   кілька адрес на користувача (дім, робота)
*   графік на сьогодні/завтра: періоди, шкала доби, скільки годин без світла, «що зараз»
*   сповіщення, коли графік змінився (показує, що саме додали/скасували) або опубліковано графік на завтра
*   нагадування за 15/30/60 хв до відключення
*   алерт адміну, якщо джерело даних перестало відповідати

**Регіон:** Івано-Франківськ та область (Прикарпаттяобленерго, дані з публічного API svitlo.oe.if.ua).
